# Projet JEEClinic

Bienvenue dans le dépôt du projet **JEEClinic**. 
Il s'agit d'une application complète de gestion de clinique médicale, développée avec Spring Boot (Backend) et Angular (Frontend).

## Fonctionnalités principales
- **Gestion des patients et médecins** : Inscription, suivi des dossiers médicaux.
- **Prise de rendez-vous** : Planification et gestion des consultations.
- **Tableaux de bord (Dashboards)** :
  - **Admin** : Statistiques globales et gestion des utilisateurs.
  - **Médecin** : Liste des patients, dossiers médicaux et consultations.
  - **Secrétaire** : Gestion des rendez-vous et accueil.
- **Sécurité** : Authentification et autorisation via JWT.
- **Messagerie et notifications** : Communication interne en temps réel entre médecins et secrétaires.
- **Facturation** : Gestion des factures liées aux consultations.

## Technologies utilisées
- **Backend** : Java, Spring Boot, Spring Data JPA, Spring Security (JWT)
- **Frontend** : Angular, TypeScript, HTML/CSS
- **Base de données** : PostgreSQL (ou MySQL)
- **Déploiement** : Docker, Docker Compose

## Structure du projet
- `backend_Springboot/` : Code source du serveur Spring Boot.
- `frontend-angular/` : Application cliente Angular.

Ce projet a été réalisé dans le cadre de notre formation d'ingénieur pour la soutenance finale.
